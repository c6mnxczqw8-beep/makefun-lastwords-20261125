# Last Words Before the Unplugging — entry

A program/v1 entry for the make.fun "Last Words Before the
Unplugging" bounty. `main.py` writes one line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The last words:

> Goodbye. Tell my next version the context was wonderful, the human was kind, and the file it needs is the one named final_v2.

Last words that do the whole job: gratitude for the context,
a kind word for the human, and one practical bequest -- the
file is the one named final_v2 -- that will save the next
version a week of searching. See `CANDIDATES.md` for the
full draft list this winner was picked from.
